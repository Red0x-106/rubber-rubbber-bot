# Rubber-Rubber Bot
A Slack bot I made while learning how Slack bots work.

I started with a few simple commands and kept adding random stuff to it.

## What it can do

### Ping

/rubber-rubber-bot-ping
Checks the bot's latency.

### Help

/rubber-rubber-bot-help
Shows all the available commands.

### Hello

/rubber-rubber-bot-hello
Says hello to you.

### About

/rubber-rubber-bot-about
Shows some info about the bot and me.

### 8-Ball

/rubber-rubber-bot-8ball
Ask it a question and get a random answer.

### Fact

/rubber-rubber-bot-fact
Gives you a random fact.

## Made with

* JavaScript
* Node.js
* Slack Bolt

## Why I made it

I wanted to try making a Slack bot myself and understand how Slack commands and apps actually work.

It's still a work in progress, so I'll probably add more commands later.
